# Kalyan — Fullstack Developer Portfolio

A standalone portfolio for Kalyan Bavisetti, a fullstack developer with 4+ years of experience. It features an interactive 3D-styled avatar, browser speech, a 360° rotation control, project filters and details, responsive navigation, and contact links. It highlights enterprise work for South Coast AQMD (SCAQMD) and the independent ENFTestHub browser-testing direction.

## Run it

No Node.js, npm, pnpm, React, jQuery, or build tools are required.

1. Open the `C:\Portfolio` folder in File Explorer.
2. Double-click `index.html` to open the portfolio in your browser.

The app uses regular HTML, CSS, and JavaScript. Avatar speech uses the browser's built-in speech synthesis, so it works in browsers that support that feature. Contact buttons open email, LinkedIn, and GitHub links.

## Files

- `index.html` — page content and structure.
- `styles.css` — layout, responsive styling, and CSS 3D avatar effects.
- `script.js` — project cards, filters, details dialog, navigation, speech, and avatar rotation.
- `public/assets/portrait.webp` — profile portrait.
- `public/assets/Kalyan_Updated_CV.pdf` — résumé download.

Enterprise project descriptions are based on the information Kalyan provided. The project graphics are original abstract illustrations and do not reproduce internal SCAQMD screens or production data. Dates and project results not provided by Kalyan are omitted.
